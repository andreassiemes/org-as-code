# OKF Export Example

This directory is **example output**: a conformant [OKF v0.1](https://github.com/GoogleCloudPlatform/knowledge-catalog) bundle
generated by `orgspec export --target okf` from `source/opi.yaml` (an OPI v0.6 document).

It reproduces the worked example in `spec/opi-v0.6.md` §12. The OPI source remains the single source of truth (Design Decision D9);
this bundle is a regenerable, portable projection — readable by any OKF reader with no OPI-specific tooling.
Every non-reserved `.md` carries YAML frontmatter with a non-empty `type`; `index.md` declares `okf_version: "0.1"`; `log.md` is the provenance surface.
